# Диск — домашнее облако

Сайт-хранилище на своём компьютере: файлы лежат обычными папками на диске, вход только по паролю.

## Запуск

1. Нужен Python 3.11 (python.org, при установке отметить «Add python.exe to PATH»).
2. Двойной щелчок по `start.bat`. При первом запуске он сам создаст окружение `.venv` и поставит пакеты из `requirements.txt`.
3. Открыть адрес из окна программы: `http://localhost:5000` на этом ПК или `http://<адрес ПК>:5000` в домашней сети.
4. При первом входе создаётся администратор и выбирается хранилище (папка или весь диск, например `D:\`).

Настройки (необязательно): скопировать `.env.example` в `.env` и поменять нужное (название, порт, хранилище, предел загрузки).

## Пользователи

- **Ограниченный доступ**: своя папка `Пользователи\<имя>` и лимит в ГБ, который задаёт администратор.
- **Полный доступ**: всё хранилище целиком, без лимита.
- Администратор всегда видит всё и управляет пользователями. Доступ меняется кнопкой «Доступ» на странице «Пользователи».

## Где что лежит

- `data\` — база, ключ сессий и корзина (рядом с программой или `DATA_DIR` из `.env`).
- «Настроить заново» удаляет пользователей, альбомы, ссылки и корзину (перед этим два подтверждения и пароль администратора).
  Файлы в хранилище не трогаются, копия базы сохраняется в `data\cloud_disk.db.backup-<дата>`.
